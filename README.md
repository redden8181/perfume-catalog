# Ароматека — личный каталог парфюмов

Мобильное PWA-приложение для ведения собственной коллекции парфюмерии.
Главная идея: выбираете парфюмерные ноты (малина, мускус, ваниль…) — приложение
мгновенно показывает ароматы, в которых они есть.

- Тёмная и светлая темы (переключатель — в шапке каталога и в Настройках), мгновенное применение без мерцания
- Премиальный минималистичный дизайн, mobile-first, заточено под iPhone
- Работает **полностью офлайн** (Service Worker + локальное хранилище)
- Автоматически **обновляется на телефоне** после каждого `git push`
- Никаких серверов и регистраций: данные хранятся на устройстве
- Экспорт/импорт всего каталога в JSON — данные никогда не потеряются

## Возможности

- **Поиск по нотам** — несколько нот одновременно, режимы «содержит ВСЕ выбранные
  ноты» и «содержит ЛЮБУЮ из выбранных»
- **Поиск текстом** — по названию, бренду и нотам
- **Фильтры** — бренд, пол, год выпуска, минимальный рейтинг, избранное
- **Добавление и редактирование** парфюмов: фото, пирамида нот (верх/сердце/база),
  описание, характеристики, личные заметки, рейтинг, избранное
- **Умный ввод нот** — автодополнение по существующим («мал…» → «Малина»),
  дубликаты «Малина»/«малина» невозможны
- **Интерактивные ноты** — тап по ноте в карточке → все ароматы с этой нотой
- **Избранное** и **личные заметки** с автосохранением
- **Импорт/экспорт JSON** — резервная копия и перенос между устройствами

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build    # соберёт dist/
npm run preview  # локальный просмотр собранной версии
```

## Публикация на GitHub Pages (один раз)

1. Создайте репозиторий на GitHub и запушьте код:

   ```bash
   git init
   git add .
   git commit -m "Ароматека: первая версия"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории откройте **Settings → Pages** и в пункте **Source**
   выберите **GitHub Actions**.

3. Готово. Сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<репозиторий>/`

## Как работает авто-деплой

Файл `.github/workflows/deploy.yml` запускается после каждого push в `main`:

```
git push → GitHub Actions → npm install → npm run build → deploy → обновлённый сайт
```

Ничего вручную загружать не нужно. Ход сборки виден во вкладке **Actions**.

## Как приложение обновляется на телефоне

Service Worker (`public/sw.js`) загружает HTML в режиме network-first:
при каждом открытии приложения с интернетом оно проверяет свежую версию.
Обновили код → push → через минуту сайт обновлён → при следующем
открытии на телефоне уже новая версия. Офлайн приложение работает из кэша.

## Установка на iPhone

1. Откройте сайт в **Safari**.
2. Нажмите **«Поделиться»** → **«На экран “Домой”»**.
3. Запускайте с иконки — приложение работает в полноэкранном режиме, офлайн,
   со своим именем и иконкой.

## Работа с данными

- Всё хранится в `localStorage` браузера (ключ `aromateka.catalog.v1`).
- **Настройки → Резервная копия**: экспорт JSON (файл/шеринг/буфер) и импорт
  (объединение или полная замена).
- При смене телефона: экспорт на старом устройстве → импорт на новом.

## Как расширять

- **Замена хранилища на API/базу**: реализуйте `StorageAdapter`
  (`src/core/storage.ts`) поверх fetch и передайте новый адаптер в
  `CatalogStore` — UI менять не придётся.
- **Новые поля парфюма**: расширьте `Perfume` в `src/core/types.ts`,
  миграцию сделайте в `sanitizeImport`/`loadFromStorage`.
- **Темы**: тёмная и светлая уже реализованы через CSS-переменные
  (`@theme` + `[data-theme="light"]` в `src/index.css`, переключатель —
  `src/state/ThemeContext.tsx`). Все компоненты используют только токены,
  поэтому новая тема = новый набор переменных.
- **Импорт из Fragrantica и т.п.**: добавьте отдельный модуль в `core/`,
  который возвращает `PerfumeDraft`, и переиспользуйте форму добавления.

## Демо-данные

При первом запуске создаются 6 ароматов и 14 нот, чтобы сразу проверить
фильтрацию: «Малина» → 2 аромата; «Малина + Мускус» (режим ВСЕ) → 1;
«Мускус + Ваниль» → 2. Сбросить/удалить их можно в Настройках.
